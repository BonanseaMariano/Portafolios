## Descripción

Este proyecto es una página web de portafolio personal que incluye secciones como inicio, sobre mí, servicios, portafolio de proyectos y contacto. La página está diseñada para ser responsiva y fácil de navegar.

La página se encuentra desplegada a través de Netlify y se puede visualizar en este enlace: [marianobonansea.netlify.app](https://marianobonansea.netlify.app/)

## Tecnologías

- HTML5
- CSS3
- JavaScript
- [Boxicons](https://boxicons.com/)
- [ScrollReveal](https://scrollrevealjs.org/)
- [Typed.js](https://github.com/mattboldt/typed.js/)
